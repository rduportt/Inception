# Inception

> A small Docker infrastructure running inside a virtual machine.

## What's inside

- Docker and Docker Compose
- Nginx with TLS (TLSv1.2 / TLSv1.3)
- WordPress with php-fpm
- MariaDB
- Volumes, networks and environment secrets

## Usage

```bash
make
```
The site is then reachable at `https://<login>.42.fr`.
